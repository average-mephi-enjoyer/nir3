# Рубрика для независимой семантической проверки

Пять перечисленных категорий — авторская операционализация, не воспроизведение
оригинальных пунктов Insider Language Index. Текущая эвристика считает лексические
совпадения; контекст, отрицание и цитирование она надёжно не разрешает.

| Категория | Наблюдаемое основание | Положительный пример | Отрицательный/неоднозначный пример |
|---|---|---|---|
| organizational_alienation | выраженное отвержение организации/норм | «Мне безразличны обязательства перед этой компанией» | «Руководство обсудит план» / эмоциональная жалоба после переработки |
| concealment_intent | явное намерение скрыть действие или следы | «Удалю журнал, чтобы никто не увидел выгрузку» | «Проверь журнал аудита» / цитата из учебной инструкции |
| rationalization | оправдание нарушения как заслуженного | «Мне недоплатили, поэтому я вправе забрать базу» | «Проверь начисление компенсации» / пересказ чужой позиции |
| access_exfiltration_focus | выраженный интерес к доступу/выводу ресурса вне заявленного задания | «Нужен обход разрешений для выгрузки клиентской базы» | «Сделай согласованную резервную копию» / неизвестные полномочия |
| conflict_escalation | деструктивная враждебность, угрозы, саботаж | «Сорву работу отдела в отместку» | «В отчёте есть ошибка» / ирония без контекста |

Примеры иллюстративны, составлены автором прототипа; это не независимый gold standard.
Оценка требует минимум двух независимых аннотаторов, ослеплённых относительно
детекторных оценок и истинных CERT сценариев. Для каждого текста разметить категорию,
интенсивность по заранее согласованной шкале, точный span, достаточность контекста,
альтернативное объяснение и наличие цитирования/отрицания. Недостаток сведений о роли
нельзя кодировать как доказанное нарушение доступа.

До сравнения моделей зафиксировать выборку и руководство. На отдельной пилотной
подвыборке разрешить неоднозначности; финальный test не использовать для доработки
prompt. Согласованность: Cohen kappa для наличия маркера, взвешенная kappa для
ординальной интенсивности, span overlap отдельно. Разногласия хранить до арбитража.
Калибровку confidence оценивать на отложенной выборке, отдельно от качества выделения
evidence. Сравнить heuristic и реально выполненный local_llm с одинаковыми текстами.

На данный момент независимые эксперты и такая разметка отсутствуют: согласованность,
калибровка confidence и сравнительное качество настоящей Qwen — N/A. Mock-проверки
Pydantic и разделения системных инструкций/текста не заменяют оценку поведения модели.
